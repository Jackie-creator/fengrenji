# ruassist（俄语助手）

面向中文母语学习者的**离线**俄汉词典与学习工具。对标法语助手／德语助手／西语助手的功能骨架，
按俄语的实际难点重新设计数据层。

> 与本仓库的 LeatherPattern AI（见根目录 `README.md`）无关，是暂时寄放在同一仓库的独立项目。
> 所有文件自包含在本目录下，将来可整体迁出。

## 核心原则

> **作者提供分类与意义，引擎提供词形。**

词条不存储变格变位形式。作者标注扎利兹尼亚克范式索引，构建期由形态引擎展开成完整词形表；
只有补充形式（мать 的 -ер-、идти 的 шёл）才手写。手写面越小，静默错误越少。

同理，**运行时不调用任何模型**。用户看到的每一个字都是构建期固化好的确定性数据。

## 为什么俄语不是"把法语换个皮"

- **形态爆炸**：名词 6 格 × 单复数；形容词性数格一致 + 短尾；动词有体的对立、
  4 种形动词（各自还要变格）、副动词——一个动词词条实际词形超过 100 个。
  词形还原不是加分项，是能不能用的前提。
- **重音**：不写、不规则、且在词形变化中移动（го́род → города́，рука́ → ру́ку），
  还辨义（за́мок 城堡 / замо́к 锁），并决定发音。**每一个词形都必须带重音标注。**
- **输入**：中国用户没有西里尔键盘，虚拟键盘 + 拉丁转写输入（`privet` → привет）是刚需。

### 形态引擎

扎利兹尼亚克索引 → 完整词形表，每个词形都带重音：

- **名词**：1–8 变格型 × a–f 重音型（含 d′ 宾格例外）、逃逸元音、动物性决定第四格
- **形容词**：软硬变化、-о́й 型末重音、о/е 随重音交替
- **动词**：能产类 1/4/5/6，含辅音交替与 л 插入音；补充形式走 `form_overrides`
- **词形还原**：歧义全量返回——`ста́ли` 同时给出 стать 和 сталь

正确性不靠自称：`crosscheck` 把生成的每个词形与 OpenCorpora 逐格比对。
**OpenCorpora 有权威词形但完全没有重音**，分工正好——它裁定拼写，我们负责重音。

> **这也是它的边界**：重音类标错时，只有在改变了拼写的情况下才会暴露。
> знакомиться 的重音类写成 4c（应为 4a），现在时形式的拼写不受影响，
> 一直到命令式变成 знакоми́сь 而不是 знако́мься 才被抓出来。
> 所以 100% 一致**不等于**重音全对，重音仍需人工核对。

> 目标词表 `data/wordlists/core_a1.yaml` 是**自建**高频表，按主题组织，
> **不是官方考纲的照抄**。高考俄语考纲、ТРКИ 官方词表需另行获取后比对补齐。

### 查询层

四级匹配，前一级有结果就不往下走——只按编辑距离排序会让精确匹配被更短的邻词埋掉：

| 级别 | 例 |
|---|---|
| 精确（含任意词形） | `книге` → книга，`стали` → стать + сталь |
| 拉丁转写 | `gorod` → город |
| 前缀 | `говор` → говорить |
| 模糊（限定编辑距离） | `челавек` → человек |

漏标重音和 ё 写成 е 在 `search_key` 阶段就被吸收，不占用编辑距离预算。

### 离线前端（PWA）

`frontend/` 是 Vite + React + TS，构建期把词包烤进静态站点，运行时零网络请求：

- 查词界面、**西里尔虚拟键盘**、拉丁转写提示
- 完整变格／变位表（名词 6 格×2 数、动词人称+过去时+命令式、形容词性数格）
- **重音显示开关**——初学者要，进阶者不要
- 体对／运动动词对可点击跳转
- Service Worker 缓存优先：飞机上、教室里没信号也能查

### 学习层

- **生词本**：查词结果一键收词，存 localStorage，没有账号也没有服务器
- **间隔重复**：SM-2 变体 + 学习步骤（1 分钟 → 10 分钟 → 天）。遗忘时间隔**减半而非清零**——
  重学比冷启动快，清零等于惩罚用户来复习
- **三种题型**，各打一个薄弱面：

  | 题型 | 问法 | 针对 |
  |---|---|---|
  | 认词 | 俄 → 中 | 基础识别 |
  | 拼写 | 中 → 俄（手输） | 认得出 ≠ 写得出 |
  | **重音** | 重音在哪个音节 | **俄语特有**——不考重音，学习者会一直读错而不自知 |

- **词书**：按词条 `lv` 标签生成的视图，不是另一份清单，词库改了词书跟着改

### 撰写标准

批量词条：语法字段必填，`common_errors` 只在真有坑的词上写。
最初 55 条样例是刻意写满的难样本，用来验证 schema 扛不扛得住真实数据：

- **体对动词** читать/прочитать、писать/написать、делать/сделать、говорить/сказать、
  брать/взять、покупать/купить
- **运动动词** идти/ходить、ехать/ездить、пойти —— 含补充形式 шёл、поезжа́й
- **重音移动名词** рука、нога、голова、вода、город、дом、окно、стол、сестра、слово
- **不规则变格** мать、дочь、имя、время、путь、человек→люди、ребёнок→дети
- **形容词** 硬/软变化、补充比较级（хороший→лу́чше、маленький→ме́ньше）
- **同形词与还原歧义** мир¹/мир²、стать 与 сталь 的 `ста́ли`
- **虚词** 代词、数词 2–4 与 5+ 的名词格规则、前置词一词多格

## 快速开始

```bash
cd ruassist
pip install -e ".[dev]"

python -m ruassist.validate data/lexicon   # 校验词库
python -m pytest                           # 跑测试
python -m ruassist.build                   # 编译离线词包

cd frontend
npm install
npm run dev                                # 开发服务器
npm run build                              # 产出纯静态 dist/
```

`validate` 会打印统计摘要，并列出所有 `verify` 待核对项——发布前这份清单必须清空。

前端读的 `frontend/public/dictionary.json` 是 `ruassist.build` 生成的，没有入库——
避免它和 YAML 词库脱节。**跑前端之前先跑一次 build。**

## 目录

```
ruassist/
├── docs/SCHEMA.md          # 词条 schema 定稿 + 形态引擎接口约定
├── data/
│   ├── lexicon/*.yaml      # 手写知识库
│   └── wordlists/*.yaml    # 目标词表（进度基准）
├── src/ruassist/
│   ├── schema.py           # schema 的可执行定义（Pydantic）
│   ├── stress.py           # 重音处理（项目地基）
│   ├── lexicon.py          # 加载 + 跨条校验
│   ├── morphology/         # 形态引擎：范式 → 带重音的词形表
│   ├── index.py            # 词形 → 词元索引（歧义全量返回）
│   ├── translit.py         # 拉丁转写输入（privet → привет）
│   ├── search.py           # 四级匹配（精确／转写／前缀／模糊）
│   ├── build.py            # 编译离线词包（JSON + SQLite）
│   ├── cli.py              # 查词 CLI
│   ├── validate.py         # 校验 CLI
│   ├── coverage.py         # 覆盖率 CLI
│   └── crosscheck.py       # 与 OpenCorpora 比对
├── frontend/               # Vite + React + TS 的离线 PWA
│   └── src/dictionary.ts   # 前端查询，与 search.py 同一套分级逻辑
└── tests/                  # 含针对词库本身的回归测试
```

## 路线图

- ✅ **M0 数据地基**：schema 定稿、重音规范、校验器、50+ 词样例

- ✅ **M1 形态引擎**：范式展开、词形还原（含歧义候选）、CLI 查词、OpenCorpora 交叉核验

- ✅ **M4 学习层**：生词本、间隔重复、三种题型、词书视图

## 规模预期

法语助手的词库是几十万条，本项目不对标那个数字。学习者约 95% 的查词落在前 5,000 词以内，
我们用**中文释义质量、体的用法说明、中国学生常见错误提示**换规模——
这些正是开源俄语数据的空白，也是通用双语词典给不了的东西。
